## Critical Finding

### 91.3% Freight Volume Loss in Preprocessing

The current data pipeline loses **240.7 billion tkm (91.3%)** of freight volume between raw data and final model input.

**Numbers:**
- **Original Data:** 263.6 billion tkm, 1.5M routes
- **Final Model Input:** 22.9 billion tkm, 2,928 routes
- **Loss:** 240.7 billion tkm (91.3% of total freight)

### Root Cause

**File:** `SM_preprocessing_nuts2_complete.py`
**Lines:** 631-643 (route validation filter)

The filter is **excessively restrictive**:
- ❌ Removes ALL local routes (origin == destination NUTS-2)
- ❌ Removes ALL entering routes (external → internal)
- ❌ Removes ALL leaving routes (internal → external)
- ❌ Removes ALL through routes (external → external)
- ✓ Only keeps internal routes (both endpoints fully inside corridor)

**Result:** 99.8% of routes filtered out (1,514,573 → 2,928)

## Quick Fix Recommendations

### Priority 1: Fix Route Validation Filter (CRITICAL)

**Current code (lines 631-643):**
```python
if origin_nuts2 == dest_nuts2:
    is_valid = False  # Removes local routes
elif origin_inside and destination_inside:
    is_valid = True   # Only keeps internal routes
else:
    is_valid = False  # Removes entering, leaving, through routes
```

**Recommended fix:**
```python
# Keep internal routes (INCLUDING local routes)
if origin_inside and destination_inside:
    is_valid = True if (origin_node and dest_node) else False

# Keep entering routes (external -> internal)
elif not origin_inside and destination_inside:
    is_valid = True if dest_node else False

# Keep leaving routes (internal -> external)
elif origin_inside and not destination_inside:
    is_valid = True if origin_node else False
```

**Expected impact:** Retain 91.3% more freight volume
